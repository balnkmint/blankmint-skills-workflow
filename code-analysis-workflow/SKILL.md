# 代码解析与文档生成

## 用途

对陌生或大型代码库进行系统性阅读，产出结构化的 Markdown 技术分析文档。适用于任意语言、任意领域的代码库，也适用于局部任务（追踪单个函数、补充模块分析、校验已有文档）。

## 文件约定

默认输出为用户指定路径。无指定时在项目根目录创建 `代码分析.md`。文档使用单一 Markdown 文件，一级标题分大节、二级标题分小节。

## 入口定位

从以下入口点开始追踪代码（按语言和场景选择）：

| 入口类型 | 定位方法 | 典型标志 |
|---------|---------|---------|
| 程序主函数 | 搜索 `int main(` / `func main()` / `if __name__` | 程序入口 |
| 线程/协程入口 | 搜索 `pthread_create` / `go func` / `async def` / `Thread` | 并发程序 |
| 框架入口 | 搜索路由注册、中间件、注解 | Web/微服务框架 |
| 内核入口 | 搜索 `module_init` / `initcall` | 内核模块 |
| 钩子/回调 | 搜索 `register` / `hook` / `callback` / `subscribe` | 事件驱动 |
| RPC/API | 搜索 `export` / `@app` / `@RestController` / `grpc` | 服务接口 |
| 定时任务 | 搜索 `cron` / `schedule` / `timer` / `setInterval` | 周期任务 |

不确定关键字位置时用广度搜索，已知函数名或模式时用精确搜索。独立文件用并行读取减少上下文切换。

## 调用链追踪规则

- 先读函数签名和开头，确认参数和前置检查
- 沿主路径深入，遇到分支只记录分支条件不展开
- 标注 `文件名:行号`，便于回溯
- 跨层时标注层切换，如 `[客户端 → 服务端]`、`[用户态 → 内核]`
- 记录关键数据结构，在首次出现时展开定义

## 调用链图格式

使用 ASCII 箭头图，不使用 Mermaid。符号约定：

| 符号 | 含义 |
|------|------|
| `→` | 函数调用 / 数据流向 |
| `↓` | 同一函数内向下的步骤 |
| `├──` | 分支起点 |
| `└──` | 最后一个分支 |
| `│` | 纵向连接线 |
| `[文件名:行号]` | 代码位置标注 |
| `[层切换]` | 跨层调用标注 |

调用链图完整示例见 [references/analysis-template.md](references/analysis-template.md)。

## 图表格式约定

- 架构对比表：维度 × 方案的 Markdown 表格
- 数据结构层次图：ASCII 树形图展示嵌套结构
- 存储布局图：偏移表 + ASCII 图
- 交互汇总表：操作 × 子系统矩阵表

各图表的完整示例见 [references/analysis-template.md](references/analysis-template.md)。

## 代码引用格式

- 文档内引用：`文件名:行号`（如 `main.go:42`）
- 首次引用模块时给出完整路径
- 行内代码用反引号包裹
- 代码块标注语言（```go / ```py / ```ts 等）

## 文档组装

按以下顺序组装：

1. 系统总览 — 定位、模块职责表、关键数据流图
2. 逐模块分析 — 模块概述、核心 API、关键函数详解
3. 关键流程汇总 — 跨模块的完整调用链
4. 关键设计 — 处理模型、存储方式、调度策略、容错策略
5. 数据结构 — 核心结构定义、层次图、存储布局
6. 交互汇总 — 操作 × 子系统矩阵表

文档骨架模板见 [references/analysis-template.md](references/analysis-template.md)。

## 校验检查

- 调用链从入口到落点完整，无断链
- 文件名和行号标注准确，可回溯到源码
- 跨层切换标注清晰
- 数据结构定义与源码一致
- 对比表覆盖所有关键维度
- 架构图与文字描述一致
- 无未解释的缩写和术语

## 常见模式速查

### 多线程/并发程序

定位入口 → 解析启动参数 → 定位线程创建 → 逐线程分析入口/主循环/退出条件 → 分析线程间通信（全局变量、锁、队列、channel）

### 框架/Web 应用

定位路由注册 → 确认中间件链 → 追踪请求处理（鉴权 → 业务 → 响应）→ 分析数据访问层 → 分析异步任务

### 系统编程

定位模块初始化入口 → 追踪初始化链（注册 → 创建接口 → 启动工作线程）→ 定位核心回调 → 分析数据流

### 跨层交互

定位层间接口（RPC/IPC/syscall/ioctl）→ 追踪调用方（封装 → 序列化 → 传输）→ 追踪接收方（反序列化 → 分发 → 处理）→ 对比两条路径异同
