  → 组装请求                                         [client.ts:80]

## 代码引用格式

- 文档内引用：`文件名:行号`（如 `main.go:42`）
- 首次引用模块时给出完整路径（如 `/path/to/module/main.go:42`）
- 行内代码：`` `function_name()` ``
- 代码块：使用 ``` 包裹，标注语言（```go / ```py / ```ts 等）
- 调用链内代码片段：`行号 函数名(参数)`

## 修改检查清单

修改文档时检查：

- 调用链从入口到落点完整，无断链
- 文件名和行号标注准确，可回溯到源码
- 跨层切换标注清晰
- 数据结构定义与源码一致
- 对比表覆盖所有关键维度
- 架构图与文字描述一致
- 新增内容与已有章节无矛盾
- 无未解释的缩写和术语
