# 页级模板与检查清单

## PPT 内容页模板

````markdown
# 第NN页｜结论式标题

## 页面标题

一句核心结论

## 关键内容

- 关键点一；
- 关键点二；
- 关键点三。

## 参考代码

```language
最小、可读、与本页结论直接相关的示例
```

## 图片

![清晰的图片说明](/绝对路径/图片.png)

> 必要的技术边界或收束句。
````

只保留本页需要的组成部分，不要机械填满所有小节。

## 演讲稿页模板

```markdown
# 第NN页｜与PPT内容完全相同的标题

第一段说明本页要解决的问题，以及它与上一页的关系。

第二段解释页面中的关键技术关系、代码或图示。

第三段补充页面没有展开的边界、验证方法或标准含义。

最后一段自然引出下一页。

[Sources]
- /绝对路径/本地来源
- https://外部来源
[/Sources]
```

没有外部或本地来源时，不要创建空的 `[Sources]` 块。

## 单页修改检查

- 读取页面正文和对应讲稿的完整段落；
- 搜索同一术语、示例、函数名和图名在其他页面的引用；
- 修改页面正文后同步修改讲稿；
- 修改调用链或流程后检查前置介绍、用例、桩函数和覆盖率页面；
- 修改页码或标题后运行双稿验证脚本；
- 重新生成受影响的 SVG、PNG 或其他导出图片；
- 目视检查文字重叠、透明背景、裁切和可读性。

## 内容取舍

优先留在页面：

- 结论；
- 架构或流程主干；
- 关键数字；
- 最小代码；
- 必须当场看见的限制。

优先放入讲稿：

- 背景和历史；
- 标准条款解释；
- 设计取舍；
- 边界条件；
- 失败路径；
- 来源和证据说明；
- 从上一页到下一页的过渡。
